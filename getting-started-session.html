Tokenizers

Tokenizers break text into the chunks that LLMs actually process. Try pasting the same sentence into both tools below and compare how they split it up.

OpenAI Tokenizer

Official OpenAI tool to visualize how text gets split into tokens.

Tiktokenizer

Interactive tokenizer explorer with support for multiple models.

System Prompts

System prompts are the hidden instructions that shape how an LLM behaves. See what a real production system prompt looks like.

Claude System Prompts

Anthropic's published system prompts for Claude, showing how production AI systems are configured.

Hands-on

Time to get your hands dirty. Use the simulation website to experiment, and grab a Groq API key to try calling LLMs programmatically.

Thousandmiles Simulation Website

Interactive simulations to help you understand LLM concepts visually.

Groq Console (Get API Key)

Sign up and grab a free API key to call LLMs at lightning speed.

Running Local Models

You don't need cloud APIs to run LLMs. These tools let you download and run models directly on your laptop.

Ollama

Run open-source LLMs locally from the command line. One command to download and start chatting.

LM Studio

Desktop app to discover, download, and run local LLMs with a clean UI.

Agentic AI Demos

See AI agents in action. Agents go beyond simple chat by using tools, making decisions, and executing multi-step tasks.

Agentic Classroom (GitHub)

Hands-on demos and examples of agentic AI patterns you can run yourself.
